# GW2 API Test

This is a test project to play with the [GuildWars 2 API](https://github.com/arenanet/api-cdi).

## Roadmap
* Legendary Finder ``work in prgogress``
  * Read all characters and equipments to check which legendary weapon is the best to craft next
  * Select characters and equipment tabs to exclude
  * Ignore all weapons which could be replaced by an owned legendary
* Achievement Sync
  * add multiple api keys to look for open achievements which can be done in the group
